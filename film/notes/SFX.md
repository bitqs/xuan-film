# 《选》音效小库（public/sfx/，48 kHz 立体声 24-bit，峰值统一 −1 dBFS）

## v2 改动（2026-10-14 用户反馈：「有个总出现的音效太吵了，换个合理的」「bgm 换成写作就是思考本身那个」）
- **shimmer 停用**（34 次、高音玻璃粒、只比人声低 6.5 LU = 吵的那个）。场景里改写 `'gather'`，`scenes/preview.tsx` 的 `VARIANTS` 按出现顺序轮换
  `gather_1/2/3.wav`：纸张飘落声倒放（越聚越密）+ 一张纸轻落，低通 6.5 kHz，无音高；文件瞬时峰值 −17 LUFS（比 shimmer 轻约 9 dB）。
- **chime** 钟琴 D6 → 颤音琴 A5，低 3 dB；**swell** 玻璃和弦 D–A–F#–D → 空五度 A–E–A–E。原因：配乐换成 A 小调的「科普悬疑」，F# 会和底乐的 F/Dm 打架。
- 生成：`python -P -E tools/sfx_v2.py`（原文件备份在 `public/sfx/_v1/`）。**不要再跑 `score.py sfx`**，它会把 chime/swell 写回 D 调版本。
- 配乐：`tools/bed.py`（「科普悬疑」三幕剪接 + 闪避 + `tools/accents.py` 的 A 小调重音层）→ `public/music.wav`，细节在 `notes/bed.json`。
  下面表格里「配乐已经在这些点写了重拍」那条说的是 v1 的代码配乐；v2 的重拍由 accents.py 补，时刻同 v1。
- 只换声音的成片：`bash tools/remux_audio.sh v2`（Remotion 只渲音频约 70 s → −12.3 LUFS → 装回 final.mkv / 上传版 / 预览的原画面）。

## v1（下面是原始说明）

重渲：`python -P -E tools/score.py sfx`（numpy 合成 + VCSL CC0 采样加工，可重复生成）。
起音都对齐在文件 0 ms（swell 例外：它的峰值在文件末尾 2.00 s，要让它「落」在某个时刻 T，就从 T−2.00 s 开始放）。
音高类音效都在 D 宫五声音阶里，和配乐同调，不会打架。旁白期间的音量取建议值的下限。
