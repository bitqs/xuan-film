# 《选》配乐 + 音效 brief（作曲 agent）

## 这是什么片
竖屏抖音片《选》，8 分 24 秒（END = 504.0 s，以 grid.json 为准），讲姜蓝（网名「自己造船的路飞」）的书《人选天选论》和围绕他的争议。
旁白：豆包 TTS 男声（冷静、克制、纪录片感），已经排好在 80 BPM 网格上。画面：整本书三万多个字像粒子一样组成河、石头、硬币、桥、马蜂……
用户是 80 后音乐爱好者，**配乐质量是第一优先级**；不要恐怖、不要警报、不要 glitch。温暖、清澈、有东方味道但现代，像高质量纪录片/电影预告的配乐。

## 硬性要求
- **整首用代码写**（numpy 离线渲染 + CC0 采样），从第 0 小节写到最后，**不用任何 AI 音乐生成**，也不要拼接现成曲子（用户原话「配乐从头写吧 别剪辑了」）。
- 参考实现：`D:/Projects/art-evolution/tools/score_proc.py`（同一个用户上一部片的程序化配乐：网格、动机、和声、事件表、混响、stems）。采样库：`D:/Projects/art-evolution/music/samples/vcsl/`（VCSL，CC0：steinway、harp、dantranh（越南筝，可当古筝色彩）、psaltery_pluck、glockenspiel、handbells、tubularbells、framedrum、timpani、gong、ocarina、shaker…；`index.json`/`vcsl.json` 是索引）。可以照抄/改写那份代码，但**新写一个文件**：`episodes/xuan/tools/score.py`，别改 art-evolution 里的东西。
- 网格：**80 BPM，拍 = 0.75 s，小节 = 3.0 s，t = 0 是第 0 小节强拍**。全片 172.5 小节。所有事件 sample-exact 落在网格上。
- 时间表的唯一真源：`episodes/xuan/notes/grid.json`（段落起止、每句旁白的 start/end 秒、文字）。旁白总轨：`episodes/xuan/public/voice.wav`（48 kHz 单声道）。
- **旁白最大**：说话时音乐让开 300 Hz–3 kHz（编配上留空 + 按 grid.json 的句子时间做自动化闪避，句间和段落空档里音乐可以上来）。
- 第 0 帧就有声音（抖音 3 秒留存）：0.0 s 一个干净的低频冲击 + 闪光质感，不要淡入。

## 交付（都在 `D:/Projects/writingisthinking/studio/episodes/xuan/`）
1. `tools/score.py`：唯一真源，能一条命令重渲：`python -P -E tools/score.py full`（也支持 `test` 只渲前 45 s）。
2. `public/music.wav`：48 kHz 立体声，**正好 END 秒（grid.json 的 end）**，已经按旁白闪避好；和 `public/voice.wav` 1:1 相加就是成片的声音（成片最后整体响度做到 −12 LUFS，你只要保证相对电平对：旁白清楚、音乐在空档里有存在感）。峰值 ≤ −1 dBFS。
3. `work/score_preview.wav`：music + voice 混好的试听版（自己检查用），并转一个 `out/feishu_queue/配乐试听-前90秒.mp3`（前 90 秒，≤ 5 MB，**写到 queue 里会自动发飞书给用户**；文件写完再放进去：先写 `_tmp` 名再改名）。全曲完成后再放一个 `out/feishu_queue/配乐试听-全曲.mp3`（≤ 25 MB）。
4. **音效小库** `public/sfx/*.wav`（48 kHz，干净、短、不吓人，numpy 合成或 VCSL 采样加工）：至少有 `shimmer`（字粒子聚拢的闪光）、`swell`（2 s 上扬）、`boom_soft`（低频冲击）、`chime`、`bell`、`drop`（水滴）、`water_loop`（10 s 可循环溪水）、`coin_flip`、`coin_land_hi`（正面）、`coin_land_lo`（反面）、`scratch`（划痕）、`crack`（石头裂开，柔）、`pebbles`（小石子堆叠）、`buzz`（柔的嗡嗡声，3 s）、`swat`（挥手破风）、`page`（翻页）、`whoosh_soft`、`tick`。写 `notes/SFX.md`：每个文件一行（名字、时长、用途、建议音量 0.1–0.4）。**音效库请先做（前 25 分钟内交）**，场景组要用。
5. 进度：每做完一步往 `out/agents/配乐.status` 追加一行（≤ 40 字，中文），飞书循环会每 10 分钟带上最后一行。
