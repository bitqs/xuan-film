# 《选》是怎么做出来的

一条 8 分 05 秒的抖音竖屏视频，用 AI 把姜蓝的《人选天选论》从头讲了一遍。这里是它的制作过程、用到的工具和全部代码。

![《选》画面：开场、整本书一页、29,604 个汉字、片名「选」、蓝光石头、硬币、拱桥、道痕](docs/img/frames.jpg)

## 写在前面

方向由抖音号「爽哥说」来定，具体制作几乎全部由 AI 完成：读书、写稿、配音、画面和音效，都是 AI 写代码做出来的。

第一版从开工到成片用了 1 小时 41 分钟（2026 年 10 月 13 日 23:45 到 10 月 14 日 01:26）。第二版画面没动，只换了配乐和一个音效。

## 核心创意：整本书就是素材

画面里几乎所有东西，都是这本书自己的字拼出来的。全书 34,952 个字符（其中汉字 29,604 个），每一个都是一粒会发光、会飞的粒子。镜头推近时，每一粒都是书里真实的字，读得出来。

- **开场**：「人选祸 天选福」由全书的字拼成，炸开后铺成整本书的一页（140 列 × 250 行，正好一屏）。镜头扎进序言，那句道歉在书里亮起来，最后所有字飞成一个巨大的「选」。
- **原文句**：旁白里有 31 句是书里的原话。画面会在整本书里找到这句话并把它点亮，配上「原文 · 第二章」这样的小标签，让观众看到它确实在书里。
- **照片和物件**：溪水、石头、硬币、拱桥、马蜂，都由书里的字聚拢而成。拉远看是一张照片，推近看是一个个字。
- **结尾**：又回到一个「选」字，也就是封面。

这样做有两个原因。一是好看：普通剪辑软件做不出这种画面。二是诚实：视频是用这本书本身的字把它讲出来的。

旁白的第一人称也是 AI：「我是一个 AI。这本书三万多字，我从头到尾读完了。」

## 制作流程

一共八步。前六步由一个「导演」 AI 做，第七步交给 14 个 AI 同时做，最后一步再由导演总装。

```mermaid
flowchart LR
  A[读书和查资料] --> B[写稿 82 句] --> C[配音] --> D[卡节拍 80 BPM] --> E[生成 19 张底图] --> F[搭引擎 + 制作圣经]
  F --> S1[场景 AI × 13]
  F --> S2[配乐音效 AI × 1]
  S1 --> G[总装 · 质检 · 输出]
  S2 --> G
```

1. **读书和查资料**：从 PDF 里抽出全书文字，序加七章。顺手修正抽字错误，比如「口」被抽成了「又」。人物经历另外参考了两篇媒体报道（2023 年 8 月扬子晚报紫牛新闻、2025 年 11 月广州花城）。
2. **写稿**：旁白共 82 句、2,058 字，分九段：冷开场、他是谁、三个词、一条河、蓝光、硬币和小石头、天权、每天捞一块石头、苍蝇还是马蜂。每句都标了出处：原文 31 句，改写 38 句，其余是媒体报道、网传说法和 AI 串场。见 [`film/script/script.json`](film/script/script.json)。
3. **配音**：用豆包语音 2.0 的「高冷沉稳」男声逐句合成，风格提示是「像纪录片旁白」。合成时同时拿到每个字的时间，画面就能跟着字走。
4. **卡节拍**：把 82 句排到每分钟 80 拍的网格上，句子从拍点上开始，全片定长 8 分 05 秒。再按内容切成 14 个场景。
5. **生成底图**：19 张写实竖图，包括神农架的溪水、夜里的船厂、熊猫纪念币、晨雾里的石拱桥和逆光的马蜂。表现真实事件的图，角上都标了「AI 示意图」。提示词见 [`film/tools/seedream_prompts.json`](film/tools/seedream_prompts.json)。
6. **搭引擎、定规矩**：导演 AI 写好字粒子引擎和第一场（冷开场），给其他 AI 当样板。另写一份「制作圣经」，规定色调（暖黑底加金色字，不吓人）、竖屏安全区、字号，还有一条硬规定：每个原文句都要让观众看到出处。见 [`film/notes/BIBLE.md`](film/notes/BIBLE.md)、[`film/notes/ENGINE.md`](film/notes/ENGINE.md)。
7. **14 个 AI 同时开工**：剩下的 13 个场景各交给一个 AI，另有一个 AI 负责配乐和音效。每个 AI 只改自己的文件，自己渲联系表自查，做完把预览发到飞书。一个场景用了 18 到 37 分钟。每个场景的任务书在 [`film/notes/briefs/`](film/notes/briefs/)。
8. **总装、质检、输出**：把 14 个场景接起来，先渲一遍半分辨率，逐帧查坏帧、黑帧、卡帧和 13 处场景衔接。然后渲 1080p 正式版，响度调到 −12 LUFS，输出 24 Mbps 的抖音上传版和封面。

## 人和 AI 怎么分工

人负责定方向和提意见，其余的事 AI 都做了。「爽哥说」这次一共只说了几句话：

- 做这本书，要「特别震撼」，同时「非常易懂、精致」，封面只有一个「选」字。
- 「正向介绍」。
- 看完第一版：「整体还可以，有个总出现的音效太吵了，换个合理的。bgm 换成《写作就是思考本身》那个。」
- 提供第二版的配乐「科普悬疑」。

AI 的部分分两层：

- **导演**：一个 Claude Code 会话（模型是 Anthropic 的 Claude Opus 5.5）。它读书、写稿、配音、做引擎和冷开场，给每个场景写任务书，最后总装、质检、渲染、上传。
- **14 个子 AI**：13 个各做一个场景，1 个做配乐和音效。它们各自读制作圣经和任务书，自己想画面、写代码、渲预览自查，然后交稿。

片子里的画面创意，比如硬币划痕露出银色、字河冻成镜湖、拱桥由第五章的原文搭成，都是这些子 AI 自己想的。

## 工具清单

真正要付钱的只有三样：Claude 订阅、豆包配音和 Seedream 生图，其余都是免费开源软件或 CC0 素材。

| 环节 | 工具 | 做什么 | 费用 |
| --- | --- | --- | --- |
| 导演和写代码 | Claude Code + Claude Opus 5.5（Anthropic） | 读书、写稿、写全部代码，指挥 14 个子 AI | Claude Max 订阅；第一版用了一周额度的约 3.5% |
| 配音 | 豆包语音合成 2.0「高冷沉稳」（火山引擎） | 82 句旁白，带逐字时间 | 按字数计费，全片 2,058 字 |
| 底图 | Seedream 5.0 Pro（火山方舟） | 19 张 1080×1920 写实图 | 约 ¥0.2 一张 |
| 画面 | Remotion 4.0（用 React 写视频）、three.js 0.186（用显卡画 34,952 个字） | 全部画面和渲染 | 个人使用免费 |
| 字体 | 思源宋体（Noto Serif SC）、思源黑体 | 书页、标题和字幕 | 免费（SIL OFL） |
| 读 PDF 和做字形 | Python | 抽出全书文字，把用到的 1,530 个不同的字符画成一张字形图供显卡使用 | 免费 |
| 配乐 | 第一版：用 Python 代码现写的配乐。第二版：「科普悬疑」，由代码按小节剪接，再加上锣、大鼓和颤音琴 | 卡点、重拍、人声下自动压低 | 乐器采样来自 VCSL，CC0 |
| 音效 | Python 合成 + CC0 采样（Freesound、Kenney、VCSL） | 翻页、硬币、水声、字聚拢的纸声等 | 免费 |
| 混音和输出 | FFmpeg | 响度 −12 LUFS、限幅、封装上传版 | 免费 |
| 质检 | Python 脚本 | 逐帧查坏帧、黑帧、卡帧，统计音效响度 | 免费 |
| 交付 | 飞书机器人、阿里云盘命令行 | 发预览，传 1.4 GB 的成片 | 免费 |

电脑是一台 Windows 台式机，显卡 RTX 4080 SUPER（16 GB）。渲染 8 分钟 1080p 大约要 15 分钟。

## 修改记录

第二版画面一帧没动，只重做了声音，重新出片约 3 分钟。

| 改动 | 第一版 | 第二版 |
| --- | --- | --- |
| 太吵的音效 | 字聚拢时的「闪光」声：高音玻璃粒叮叮响，全片 34 次，只比人声低 6.5 LU | 纸张「聚拢」声：纸张飘落声倒放，最后轻轻落定。三个变体轮流用，轻约 9 dB |
| 提示音 | 钟琴「叮」 | 颤音琴，低 3 dB，和新配乐同调 |
| 配乐 | 用代码现写的 D 大调五声配乐 | 「科普悬疑」，不变速不变调，按小节剪成三段 |
| 重拍 | 写在旧配乐里 | 用锣、大鼓、颤音琴重新补上，力度和第一版接近 |

新配乐是按剧情剪的，几个关键点都落在拍上：

- 片名「选」之后鼓进来。「人选。祸。天选。」三个词正好落在三个小节头上。
- 「蓝光，也没有回来」处音乐停下，引文之后再进来。
- 拱桥合拢（5:00）时鼓第二次进来。「只要你还能问，桥就还没断」处主旋律进来。
- 「是一只很大的马蜂」处音乐停下。结尾的「选」落在原曲自己的收尾重拍上。

剪接方案见 [`film/tools/bed.py`](film/tools/bed.py) 和 [`film/notes/bed.json`](film/notes/bed.json)。

## 如果想自己做

- **电脑**：一台有独立显卡的电脑。本片用的是 RTX 4080 SUPER，显卡越弱渲得越慢。
- **账号**：Claude（用 Claude Code；同时开 14 个 AI 很耗额度，本片用的是 Max 订阅）、火山引擎（豆包配音和 Seedream 生图）。
- **软件**：Node.js、Python、FFmpeg，都免费。Remotion 和 three.js 用 npm 装。
- **换一本书**：引擎和工具可以直接用。要重做的是稿子、配音和 14 个场景，也就是重新走一遍上面的八步。

## 仓库里有什么

```
film/
  Root.tsx, index.ts         Remotion 入口：正片、无字幕版、14 个单场预览、3 种封面
  script/script.json         82 句旁白，每句标出处（原文 / 改写 / 报道 / 网传 / AI）
  storyboard/                场景切分和时间
  alignment/                 每个字的发音时间（来自配音）
  scenes/core/glyph.tsx      字粒子引擎：34,952 个字一次画完（three.js 实例化渲染）
  scenes/core/look.tsx       色板、安全区、标题、引文卡、照片层
  scenes/core/timeline.ts    时间工具：at('词') 拿到某个词开口的帧，nextBeatF 找下一个拍点
  scenes/s/A.tsx … I2.tsx    14 个场景（A 冷开场由导演做，其余 13 个由子 AI 做）
  scenes/Video.tsx           总装：场景衔接、字幕、水印、声音
  dev/                       每个场景单独的预览入口（一个场景写坏了不影响别的）
  notes/BIBLE.md             制作圣经（所有子 AI 必读）
  notes/ENGINE.md            引擎速查
  notes/briefs/              13 份场景任务书
  notes/SFX.md               音效清单和用法
  tools/                     Python / Shell 工具：抽字、配音、卡节拍、生图、配乐、音效、质检、渲染、出封面
  public/img/                19 张 Seedream 底图
  public/sfx/                音效（_v1/ 是第一版被换掉的）
docs/img/                    本页截图
```

常用工具：

| 文件 | 作用 |
| --- | --- |
| `tools/build_book.py` | 全书文字 → `scenes/core/book.json` 和字形图 `public/glyph/atlas.png` |
| `tools/tts.py` | 逐句配音，记下每个字的时间 |
| `tools/schedule.py` | 把句子排到 80 BPM 网格上，拼出整条旁白 |
| `tools/scenes.py` | 按网格切出 14 个场景 |
| `tools/seedream.py` | 调 Seedream 生成底图 |
| `tools/score.py` | 第一版配乐和音效库（全部代码合成） |
| `tools/bed.py`、`tools/accents.py` | 第二版配乐剪接和重拍 |
| `tools/sfx_v2.py`、`tools/sfx_audit.py` | 第二版音效，以及每个音效比人声低多少 |
| `tools/sheet.sh` | 单场联系表，子 AI 用来自查 |
| `tools/qa.py` | 逐帧质检 |
| `tools/render_final.sh` | 渲染正式版、调响度、出上传版 |
| `tools/remux_audio.sh` | 只换声音不重渲画面（第二版就是这样出的） |
| `tools/covers.py` | 出封面 |

**说明**：这些代码是从作者的 Remotion 工作室项目里原样拿出来的，供阅读和参考，不能直接运行。

- 它依赖工作室里的 `@kit` 和 `@ep` 路径别名，以及工作室的 `remotion.config.ts`。
- 工具脚本里写的是作者电脑上的路径。
- 配音和生图的密钥从本地的 `.env` 读取，仓库里没有任何密钥。

仓库里**没有**这些文件：

- 书的全文（`scenes/core/book.json`）和字形图（`public/glyph/atlas.png`）。要先从原书生成，原书在 [guohen.com](https://guohen.com)。
- 配音 `public/voice.wav`、配乐 `public/music.wav` 和字体文件。
